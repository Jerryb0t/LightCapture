# 轻截 · LightCapture

[English](README.en.md) | 简体中文

一个原生、精简的 macOS 截图与录屏工具。Swift + AppKit + ScreenCaptureKit，截图和录屏使用系统框架，不需要账号；只有检查更新或主动安装新版才访问 GitHub。MIT 开源。

**当前源码：0.2.5（Apple Silicon，macOS 15+）。macOS 下载包与签名更新源尚未公开发布，请勿将源码验证等同于已提供一键更新。**

**0.2.3 版后台实测：约 29 MB。** MacBook Air M5（16 GB，macOS 27.2.1），系统隐藏应用窗口后闲置 90 秒，分别在 30、60、90 秒测得应用物理内存均约 29 MB。未在录屏中测量；RSS 约 101 MB，与物理占用不是同一口径。

## 功能

- 区域、窗口吸附及全屏截图，简单画笔、箭头、矩形、文字标注。
- 默认 Control+A 打开选区，选区工具栏切换截图、长截图、录屏。默认 Enter 复制并保存，可设置为仅复制。
- 长截图：在选区界面选择长截图并框选，随后回到原页面双指缓慢滚动；Enter 完成保存、Esc 取消。滚动期间仅有鼠标穿透、不激活的细边框，不显示浮动控制窗。Enter/Esc 无法注册时保留选区并提示，不进入无法退出的会话。向上回看已拼接内容不重复增加长度；不注入自动滚动，不要求辅助功能权限。固定头栏、动画、周期重复或复杂页面可能无法可靠拼接。
- 完成时补采最后一帧；如果系统捕获超时，停止本次采样并在结果编辑器中保留已有部分供检查和保存。底层请求一直不返回时需退出后重开，避免叠加捕获任务。
- 全屏与区域录屏。分辨率和目标帧率独立设置：标准/高清最长边 1920/3840，24、30（默认）或 60 fps。帧率是目标上限，取决于画面变化、显示器和机器性能；静止画面不会强行重复写入。
- 系统声音和麦克风独立开关。未设置时默认录系统声音、不录麦克风；旧设置保留。只有打开麦克风并开始录制才请求麦克风权限。双音源在保存时混成一条可播放的声音轨，不重新编码视频。
- 录屏期间再次按同一快捷键停止并保存。控制窗尽可能避开录制区域；无空位时隐藏。也可在访达或桌面双击轻截应用，重新打开主窗口并停止。
- **没有 macOS 菜单栏状态图标**。红色关闭按钮使应用隐入后台，同时隐藏 Dock 图标和左上角应用菜单；快捷键仍可截图或停止录屏。在访达或桌面双击轻截应用会重新显示设置窗口、Dock 图标与应用菜单。彻底退出请先打开设置，再使用应用菜单。
- 可选登录后自动隐身后台运行，不弹出设置窗口，默认不注册。系统要求批准时在设置中显示状态；更新不会强制更改登录启动偏好。
- 自定义保存目录，分为截图、长截图、录屏。默认优先 iCloud Drive，未提供时使用本机图片目录。录制中间文件留在本机，成功导出后清理其临时副本。

## 语言与作者支持

同一应用支持简体中文和英语，默认跟随系统语言。要在中文 Mac 上单独使用英语：系统设置 → 通用 → 语言与地区 → 应用程序，添加轻截并选择 English，然后退出并重新打开应用。语言切换不会改变现有文件夹、保存位置或登录启动偏好；macOS 系统错误仍可能使用系统语言。

主窗口底部有两个独立入口：「👋 关注作者」仅提供 [X](https://x.com/Jerryb0t) 与 [GitHub](https://github.com/Jerryb0t) 作者主页链接；「☕ 打赏作者」仅提供自愿打赏渠道。默认不显示收款码，只有主动选择时才展示微信支付、支付宝或 OKX Pay 其中一个收款码。弹层与图片按需创建，关闭后释放；不会新增常驻计时器或网络请求，不承诺未经测量的内存数值。打赏完全自愿，请在自己的支付应用中核对收款人。轻截不会发起、处理或确认付款，不会联系支付服务。

## 手动检查更新

窗口底部可手动「检查更新」。另有「启动时自动检查更新」选项，默认关闭；开启后，仅在启动或重新打开应用时按至少 24 小时间隔检查本仓库的 GitHub releases API，没有常驻计时器或后台轮询。关闭时不自动检查；此选项不会自动安装更新。源码已接入 Sparkle 签名更新，但正式 ZIP 与签名 appcast 尚未发布，当前不提供可用的公开一键升级。发布前须完成独立的更新密钥签名和验证；不会后台下载或安装。0.2.2 及更早版本没有内置安装器。

## 环境与构建

当前构建面向 **macOS 15 或更高、Apple Silicon（arm64）**，需安装 Apple Xcode Command Line Tools（包含 Swift 与相应 macOS SDK）。在 macOS 27.2.1 / Swift 6.4.2 上编译测试；未验证 Intel 和所有旧版系统。

```sh
./build.sh
open build/轻截.app
```

默认使用本地 ad-hoc 签名，不是 Developer ID 公证发行包。构建产物在 `build/`，不要提交。可以通过环境变量 `SIGN_IDENTITY` 指定自己的合法签名身份，`BUNDLE_ID` 指定独立应用标识，`APP_OUTPUT` 指定产物路径。重新签名或移动应用可能导致 macOS 再次确认屏幕录制权限。不要关闭系统安全保护来规避提示。

首次截图/录屏需要用户在 macOS 授予屏幕录制权限。登录启动需要固定应用位置，在设置中显式勾选，可能还需系统批准。此仓库不自动注册登录项。

## 测试

```sh
./test.sh
```

运行无屏幕读取的合成数据、应用内部事件与假登录服务测试，不开启真实屏幕录制、不发送全局键盘鼠标事件、不修改实际登录项。测试不等于完整实机验收。

可选合成视频编码回归：

```sh
./test.sh --video
```

只生成合成移动图形 MP4，不捕获屏幕。某些受限执行器不允许访问系统视频编码器，失败需要与录屏功能本身区分。

可选二维码离屏渲染校验：`./test.sh --qr`。使用本地 Vision 解码，不输出支付内容，不执行支付；受限执行器中 Vision 不可用时返回 77，不能当作通过。

## 冻结截图

发起选区时，轻截先一次性读取屏幕图像和窗口顺序，再显示选区界面。 0.2.1 在系统窗口列表缺失或不完整时，会用同次预取的屏幕捕获窗口列表补齐吸附候选；仍优先使用系统提供的前后层级。 0.2.2 避免把覆盖整屏的高层系统容器当成吸附对象，并从选区窗口接收鼠标移动，让普通窗口和小弹窗可切换。确认或标注使用冻结图的原始像素，不重新抓取已经消失的菜单。可见弹层在系统提供可靠元数据时可以吸附；也可直接拖框。系统禁止捕获的内容、在预取前已经消失的弹层，以及部分特殊窗口仍可能无法正确捕获，不能保证所有弹窗均可用。

冻结帧仅在本次选区期间存在，取消或确认后释放预览引用。总预算为 2400 万像素；多屏超预算时仅冻结鼠标所在屏幕，并提示移到另一屏后重新发起。局部截图复制为独立图像，不保留整屏裁剪背板。预算不是实际进程内存测量；极端情况下系统截图 API 未返回时，旧请求资源可能延迟释放。录屏和长截图仍使用实时画面，冻结失败时从这两种模式发起可继续实时选区，但禁用本次普通截图。

冻结修复已通过合成像素、Retina、候选层级、生命周期、选区和双语布局测试；尚未进行这版真实屏幕弹窗端到端验收。

## 使用限制

全局快捷键可能与其他软件冲突，可在设置更改。按应用排除轻截自身窗口，因此录屏不会用于展示轻截本身；系统版本/多屏布局仍需实机验证。长截图、系统音频、登录启动与 iCloud 同步在不同环境中可能不同。源代码附带自动测试，但不承诺所有组合均已验证。
