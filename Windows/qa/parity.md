# 轻截 Windows 对照验收
参考行为：Jerryb0t/LightCapture macOS 公开源码 `90e690fe357a971e741ce5d3fdd9f5d6d3e10ff2`（0.2.2），以及待独立接入可信 Windows 发行渠道的一键安装更新。不将云端 PE 编译、合成测试与真实桌面验收混为一谈。下表是验收目标，不代表已经通过。

| 项目 | 必须核验的可见行为 |
| --- | --- |
| 单键 | 全新设置默认 F2；设置可切 F1/F2/Ctrl+A；冲突保留现有绑定；重启后继续使用已选键；按住不重复进入 |
| 隐藏 | 点 × 后窗口、任务栏应用按钮、托盘均不显示；热键仍可用；从开始菜单重开应重显同一进程 |
| 区域/窗口 | 拖选、吸附小对话框与普通窗口、全屏；普通拖选及鼠标点击正常提交；Enter 可复制，Esc 在任务每个阶段可取消 |
| 冻结 | 临时菜单截图实际包含冻结时的内容；拖框不会导致结果重新抓取，不能拍到自家的罩层。遇系统保护应报有限制 |
| 多屏 | 100%/150% 不同 DPI，主屏左侧负坐标与跨屏，尺寸和裁剪无偏移；冻结超预算给出提示，不能悄悄截错屏 |
| 标注与输出 | 画笔、箭头、矩形、文字至少各一例；撤销不污染原帧；复制可粘贴，复制并保存与仅复制分开；路径失败不吞错误 |
| 长截图 | 手滚动时连续采样；下一屏按钮可用；重复页、相反方向、低纹理、粘性栏、预算耗尽：不乱拼且保留可导出内容；本地测试页逐行校对 |
| 录屏 | 区域与全屏、1920/3840 × 24/30/60，录 10 秒移动内容检查每秒都画面更新；控制窗不应出现在结果；失败不留假成功 MP4 |
| 音频 | 0/0、0/1、1/0、1/1 四种源组合；系统声默认开、麦克风默认关；音轨有实际内容且可播放；未开启麦克风不请求它 |
| 文件 | 默认合适的 Windows 图片目录或可用的用户云盘，支持选择一个文件夹并分类；记录期间、取消、正常停止、文件夹不可写均检查 |
| 登录 | 默认不注册；开启后登录静默；关闭后不再自启；保持当前偏好，不修改 OS 安全 |
| 双语 | 系统中英匹配，设置、工具条、状态提示完整，快捷键与目录选择行为不变；关注/打赏入口独立、资源按需加载 |
| 更新 | 手动检查或默认关闭的启动检查；自动检查无常驻轮询；签名和版本、渠道校验失败必须拒绝安装；Windows 与 macOS 包绝不互认 |
| 常驻 | 关闭设置，空闲 30/60/90 秒采样 Private Bytes 和 Working Set；分别报告首次截图前、取消后、录屏关闭后，不拿不同口径直接和 macOS 数值比较 |

## 实机用例：采集录制证据
1. 首先检查一次输入、选区、确认、取消。每次结果核对剪贴板和文件。
2. 用可见连续时钟或滚动文章作为录屏源，确保后半段不是静帧，拖动另一个窗口穿过录制区。
3. 独立测系统声和麦克风，各源用不同音色；播放或读取音轨验证。截图中不要带入真实业务数据。
4. 普通用户权限运行；不关闭 SmartScreen 或安全设置以通过测试。未签名的工程包不得称为正式安装包。
